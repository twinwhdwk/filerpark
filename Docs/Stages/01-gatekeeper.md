# Stage 1 — 문지기 (Gatekeeper)

**테마**: 동시 입력 · **인원**: 4~6명 · **구현 상태**: 기존 컴포넌트(`CoopButtonNGO`/`CoopDoorNGO`/`GoalZoneNGO`)만으로 바로 제작 가능, 신규 스크립트 불필요.

## 개요

문 하나를 열려면 N-1개의 버튼을 동시에 밟고 있어야 한다 (N = 접속 인원수). 즉 인원 중 1명만 자유롭게 움직일 수 있고 나머지는 각자 버튼을 지켜야 문이 열려 있다. 자유로운 1명("러너")이 문을 통과해 골존에 먼저 도달한 뒤, 버튼을 지키던 인원이 순서대로 손을 떼고 릴레이로 합류한다 — 마지막으로 손을 떼는 사람은 자기 힘으로 문이 닫히기 전에 뛰어야 하므로 약간의 긴장감이 생긴다.

## 인원수 스케일링

버튼 개수 = `접속 인원수 - 1` (예: 4명 → 버튼 3개, 6명 → 버튼 5개). `CoopDoorNGO.requiredButtons`를 고정값이 아니라 `NetworkManager.ConnectedClients.Count - 1`로 서버가 스폰 시점에 계산해서 넣도록 만든다 — 지금 `CreateCoopTest`가 `requiredButtons = 1`로 하드코딩한 부분을 이렇게 바꿔야 한다.

## 레벨 레이아웃 (개념도, 좌→우 진행)

```
[스폰 지점]  [버튼1][버튼2][버튼3]...[버튼N-1]   [문]   [골존]
                └── 각 버튼 앞에 살짝 턱을 둬서
                    버튼 담당이 실수로 미끄러져
                    나가지 않게 한다
```

- 버튼들은 가로로 나란히, 각각 독립된 트리거 콜라이더 (`CoopButtonNGO`, `isTrigger`).
- 문은 버튼 열 바로 뒤, 골존은 문을 지나야 도달.
- 버튼 사이 간격은 플레이어 1명이 서 있기에 좁게(다른 봇/사람이 실수로 옆 버튼까지 같이 밟아 요구 조건을 헷갈리게 하지 않도록).

## 진행 흐름

1. 전원 스폰.
2. N-1명이 각자 버튼으로 이동해 선다.
3. 문이 열림 (`isOpen.Value == true`).
4. 나머지 1명(러너)이 문을 통과해 골존 진입.
5. (선택) 버튼 담당들이 순서대로 이탈, 마지막 인원은 문이 닫히기 전에 통과해야 함.
6. 전원 골존 도달 시 스테이지 클리어.

## 승리/실패 조건

- 성공: `GoalZoneNGO`에 접속 중인 전원이 동시에 존재.
- 실패 조건은 없음(타임어택 아님) — 이 스테이지의 학습 목표는 "동시 입력" 자체를 이해시키는 것이라 실패 페널티보다 재시도 자유도를 우선.

## 봇 자동 클리어 로직

공통 아키텍처는 [bot-coordination.md](bot-coordination.md) 참고. 이 스테이지의 역할 배정표:

| 역할 번호 | BotMode | 대상 | 인원 (N명 기준) |
|---|---|---|---|
| 0 ~ N-2 | `HoldButton` (targetIndex = 역할 번호) | `StageButton` 태그 오브젝트 중 해당 인덱스 | N-1명 |
| N-1 | `GoToGoal` (단, `CoopDoorNGO.isOpen`이 true가 될 때까지 대기 후 이동) | `GoalZoneNGO` | 1명 |

- `GoToGoal` 역할을 맡은 봇은 문이 열리기 전까지는 제자리에서 대기해야 한다 — `isOpen.Value`를 구독해서 `false`인 동안은 `HorizontalInput = 0`으로 묶어두는 대기 로직이 필요 (단순히 "문 쪽으로 걷기"를 시키면 닫힌 문에 부딪혀 멈춘 채로도 결과적으로는 맞물리긴 하지만, 명시적으로 대기시키는 쪽이 의도를 코드로 남기기에 더 낫다).
- 봇 4마리(전원 봇)로 완전 자동 검증 가능 — 이 스테이지가 4개 미션 중 자동화 신뢰도가 가장 높다. `[StageValidation]` 로그로 "버튼 N-1개 동시 점유 -> 문 열림 -> 러너 통과 -> 전원 골존" 시퀀스가 매번 재현되는지 반복 실행해 확인한다.
- **사람 플레이테스트가 필요한 부분**: "버튼 담당이 순서대로 이탈해 릴레이로 합류"하는 4단계는 자동 클리어 로직에서는 생략(버튼 담당 봇은 그냥 게임이 끝날 때까지 눌러진 채로 둬도 성공 판정에는 문제없음) — 이 릴레이 합류의 긴장감/재미는 사람이 직접 해봐야 체감된다.
